## 已确认的关键时间点

- 2026-2027 秋季学期第 1 周：2026-08-31 至 09-06。
- 全国大学生数学竞赛非数学类初赛：2026-11-14。
- 常规课程主要至第 16 周，即 2026-12-14 至 12-20；第 17-20 周用于期末、材料归档和考研不断线。
- 寒假开始：2027-01-18。

## 已确认的个人约束

1. 学院路校区，通勤使用步行或共享单车，不依赖共享电动车。
2. 13:30 有午后课时，午睡最迟 13:05 前必须起床；v1 建议短睡至 12:55-13:00。
3. 推免资格预期无问题，但不为保研额外投入；当前重点是把各科尽量提高到 91+，夏令营只作为后续机会。
4. 无明显旧伤；饮食偏好是健康、能与健身配合的长期模式。
5. 健身场所为学校附近的加州铁馆。
6. 仅有基础 Python/C，无小程序账号；成长工具由 Codex 开发，用户基于实际使用反馈迭代。

## 仍需首次运行后确认

1. 宿舍到加州铁馆、教室和食堂的实际单程分钟数。
2. 两周试运行后的真实入睡时间、午睡效果和学习完成率。
3. 加州铁馆的器械可用性和训练前后实际通勤时间。

## 执行顺序

1. 开学第 1 天启动 `学习资源选择与试学协议_v0.md` 的 14 天试学。
2. 同步按 `课表驱动执行日历_v0.md` 的平衡版执行，训练先做 A/B 两次。
3. 第 2 周结束后，用独立完成率、词汇正确率和时间记录锁定资源。
4. 以 `个人执行日历_v1.md` 开始第一周；第 2 周日依据数据做一次微调。
5. 成长工具实现使用独立工作树，不在规划文档目录直接混入产品代码。

## 版本规则

- `v0`：基于公开信息和临时假设的讨论稿。
- `v1`：用户确认的作息、校区、推免策略、训练与饮食约束后的个人执行版。
- 每一次重要调整：在 `PROJECT_MEMORY.md` 追加一条记录，说明改了什么、为何改、当前证据、未解决问题和下一步。
